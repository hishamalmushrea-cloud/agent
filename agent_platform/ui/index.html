👋 مرحبًا — جسر Arena للوكيل المحلي

  1. العقل (Arena): Arena هي الدماغ. لا تملك واجهة برمجية عامة لمزامنة المحادثة، لذا يفتح التطبيق نافذة متصفح إلى arena.ai وتستعمل الحساب الذي تعرفه.
  2. الجسر المحلي: التطبيق يكشف واجهة /api/* محليًا. منه يعمل الجسر — وهذا ما يوفّر القدرات على جهازك (ملفات، طرفية، شاشة، متصفح).
  3. الإذن: الأدوات الخطرة (حذف/أوامر) تتطلب موافقتك عبر نظام الأذونات (Allow Once / Always / Deny).
  4. أعمل فوق الإنترنت: لأنك تصل إليه عبر الإنترنت، الجسر يعمل عبر الشبكة لكن محميًا بترميز محلي + رمز + فحص الأصل.
